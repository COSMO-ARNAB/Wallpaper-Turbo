# Privacy Policy

**Last Updated:** May 29, 2026

**Wallpaper Turbo** ("the Application") is built as an open-source, offline desktop utility. This Privacy Policy governs the use of the Application and explains our commitment to protecting your privacy.

---

## 1. No Collection of Personal Data

Wallpaper Turbo is designed to run **100% locally and offline** on your computer. 
* **We do NOT collect, transmit, store, upload, or share** any personal information, location data, IP addresses, system logs, or user metrics.
* There are no tracking scripts, analytics SDKs, or remote telemetry frameworks built into the Application. 

---

## 2. Local File System & Media Handling

The Application reads files only from your local device to perform its core functions:
* **Wallpaper Media**: The Application reads video files (`.mp4` or other media formats) that you voluntarily select to play as your desktop background.
* **Configurations**: Any preferences (such as pause modes, layout styles, and imported wallpaper lists) are stored entirely locally on your hard drive inside your system's `AppData` folder.
* **Zero Network Connections**: No media or configuration data is ever transmitted to external servers. All decoding and rendering are handled strictly by your local CPU and GPU.

---

## 3. Third-Party Libraries

The Application uses third-party libraries (such as LibVLCSharp and VLC media player) to perform hardware-accelerated video decoding. 
* These libraries run completely within the local execution context of the Application. 
* No network communication, background data collection, or telemetry is initiated by these dependencies.

---

## 4. Microsoft Store Compliance

For installations distributed via the Microsoft Store:
* The Application adheres fully to the **Microsoft Store Developer Policies**.
* We do not request, access, or process any Microsoft account details or billing information. All store transactions and downloads are handled directly and securely by Microsoft.

---

## 5. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect modifications in local system structures or open-source standards. Any updates will be pushed directly to the official GitHub repository.
